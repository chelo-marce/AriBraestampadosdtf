# Mi Comercio — Aribra Estampados DTF

Aplicación web/PWA local para gestión de clientes, productos, stock, facturas, preventas, presupuestos, compras, producción, envíos y gastos.

## Publicación gratuita

Este paquete está preparado para GitHub Pages. Ver `LEEME_GITHUB_PAGES.txt`.

## Privacidad de datos

La aplicación no utiliza almacenamiento en la nube. Los datos se guardan localmente en el navegador/dispositivo y se pueden mover entre dispositivos mediante Exportar / Importar.
